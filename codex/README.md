# Codex Agent Mirror

This directory mirrors the Claude agent structure for Codex workflows.

Source of truth remains `.claude/`.

## Layout

- `codex/agents/`
- `codex/commands/`
- `codex/skills/`
- `codex/output/`

## Sync Policy

When updating agent definitions, command workflows, or skills:

1. Update files under `.claude/` first.
2. Reflect equivalent changes under `codex/`.
